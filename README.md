# Windows 9x OpenGL Screensavers
This repository contains the source code to the OpenGL screensavers as seen in Windows 9x, taken from Visual Studio 97. Comes with GLaux, a deprecated OpenGL auxiliary library that the screensavers use.

## Includes
* 3D Flower Box
* 3D Flying Objects
* 3D Maze
* 3D Pipes
* 3D Text
